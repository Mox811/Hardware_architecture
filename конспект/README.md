Краткий конспект: Работа процессора и архитектура ЭВМ

1. Рабочий цикл процессора (принцип фон Неймана)

Основные компоненты

Процессор (CPU): управляет работой всей системы и выполняет команды.
Оперативная память (ОП): хранит команды и данные (принстонская архитектура — совместное хранение).
Шины: адреса, данных, управления — обеспечивают связь между процессором и ОП.
Устройства ввода-вывода: обеспечивают взаимодействие с внешним миром.
Ключевые регистры процессора

СчАК (PC, счётчик команд): хранит адрес следующей команды.
РК (IR, регистр команд): хранит текущую выполняемую команду (состоит из полей: КОП, A1, A2).
П1 / П2 (регистры АЛУ): хранят операнды; П1 (аккумулятор) — также хранит результат.
РПР (регистр признака результата): хранит признаки (равно нулю, меньше нуля, больше нуля, переполнение).
РФ (регистр флагов): хранит флаги исключительных ситуаций (переполнение порядка, деление на ноль и т.д.).
РАОП / РСОП: регистры адреса и слова оперативной памяти.
Этапы рабочего цикла (на примере двухадресной команды)

Выборка команды: из СчАК адрес подаётся на шину адреса → сигнал чтения → команда из ОП попадает в РК.
Выборка операндов:

Адрес A1 из РК → на шину адреса → чтение → операнд в П1.
Адрес A2 из РК → на шину адреса → чтение → операнд в П2.
Выполнение операции: КОП дешифруется, АЛУ выполняет операцию, результат помещается в аккумулятор (П1).
Запись результата: результат из П1 → на шину данных → в ОП по адресу A1 → сигнал записи.
Продвижение СчАК: СчАК увеличивается на длину команды (переход к следующей команде).
2. Устройство управления (УУ)

Функции УУ

Формирование управляющих сигналов для выборки, дешифрации, выполнения команд.
Управление обменом данными между ОП и операционными устройствами.
Организация реакции на прерывания.
Типы микропрограммных автоматов

С жёсткой логикой: сигналы управления формируются фиксированной схемой (дешифратор КОП + счётчик тактов + логические схемы). Быстро, но негибко.
С программируемой логикой: управляющие сигналы хранятся в памяти микропрограмм (микрокоманды). Гибко, но медленнее. Идея предложена Морисом Уилксом (1951).
Понятия

Микрооперация — элементарное действие за один такт.
Микрокоманда — совокупность одновременно выполняемых микроопераций.
Микропрограмма — последовательность микрокоманд для реализации машинного цикла.
3. АЛУ и операционные устройства

АЛУ — комбинационная схема (без внутренней памяти), принимает два операнда и формирует результат.
Признаки результата (унитарный код на ШАЛУ): =0, <0, >0, переполнение.
Флаги исключительных ситуаций: переполнение порядка, исчезновение порядка, потеря значимости, деление на ноль.
Магистральная структура: регистры общего назначения (РОН) + операционный блок (ОПБ) + мультиплексоры + шины.
4. Архитектура системы команд (АСК)

Основные типы

Стековая: данные на вершине стека (LIFO), обратная польская запись.
Аккумуляторная: один регистр-аккумулятор; короткие команды, но частые обращения к памяти.
Регистровая: массив регистров общего назначения (РОН); команды «регистр-регистр», «регистр-память», «память-память».
С выделенным доступом к памяти (Load/Store): доступ к памяти только через load и store; характерно для RISC (MIPS, SPARC, Alpha).
Классы процессоров

CISC (Complex Instruction Set Computer): сложный набор команд, переменная длина (x86, VAX).
RISC (Reduced Instruction Set Computer): сокращённый набор, фиксированная длина команд, много регистров.
VLIW (Very Long Instruction Word): сверхдлинные командные слова.
5. Процессор Intel 8086 (пример)

Регистры: данных (ax, bx, cx, dx), указатели (si, di, sp, bp), сегментные (cs, ss, ds, es), ip, флагов (fl).
Сегментная организация памяти: физический адрес = сегмент × 16 + смещение (20-битная адресация, 1 МБ).
Регистр флагов: CF, PF, AF, ZF, SF, TF, IF, DF, OF.
Форматы команд: 1–15 байт, сложные способы адресации, двухоперандные команды (один операнд — в регистре).
Конвейер: совмещение этапов выполнения команд (выборка, декодирование, выполнение) для повышения производительности.
6. Прерывания и подпрограммы

Прерывания — события, требующие переключения процессора на обработку (исключения, внешние устройства, таймер).
Таблица векторов прерываний (ТВП): хранит адреса программ обработки прерываний.
Стек (LIFO): используется для сохранения адреса возврата и регистров при прерываниях.
Указатель стека (УС): хранит адрес вершины стека.
Регистры для прерываний: РФ (флаги прерываний), РМ (маска прерываний).
Команда RETI: возврат из прерывания (восстановление СК из стека).
7. Ключевые принципы

Принцип хранимой программы: команды и данные хранятся в одной памяти.
Последовательное выполнение: команды выполняются по порядку, СчАК автоматически продвигается.
Управление через микропрограммы: сложные команды реализуются последовательностью микроопераций.
Аппаратная поддержка: регистры, шины, дешифраторы, АЛУ, УУ — всё работает синхронно по тактовым импульсам.
